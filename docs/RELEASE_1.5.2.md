# tellev v1.5.2

本版本重点改善日常使用中的个性化、角色辨识和更新触达体验。

## 外观与聊天

- 修复主题选择持久化后界面未即时应用的问题。
- 支持为每个聊天会话单独选择背景图片，不同会话之间互不覆盖。
- 背景图片导入时进行适当缩放，降低存储和渲染负担。

## 角色头像

- 角色管理列表显示角色卡头像。
- 支持为角色选择、更换并持久化自定义头像。
- 聊天页角色选择列表同步显示头像，切换角色时更易辨认。

## 设置与社区

- 生成预设列表改为紧凑单行布局，提高大量预设下的浏览效率。
- 每次冷启动检查正式版更新，发现新版本后弹窗提示。
- 关于页、更新提示和新用户首次启动流程加入 QQ 交流群入口。

## 版本信息

- `versionName`: `1.5.2`
- `versionCode`: `19`
- 最低系统：Android 12 / API 31
- SillyTavern 兼容基线：1.18.0
