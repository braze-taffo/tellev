# tellev v1.6.2 MNN 生图版

修复场景总结，并将生图记录与聊天处理隔离。

## 更新内容

- 修复场景总结被对话预设带着续写正文的问题，改为独立提取当前画面，保留必要的剧情与角色信息。
- 改进英文生图提示词校验、重试和失败诊断，检查 ComfyUI 工作流的正向提示词绑定，避免无效内容继续生图。
- 生图结果改为独立图库，不进入聊天上下文、不占消息楼层、不触发聊天或 MVU 事件；旧生图记录自动迁移并保留图片和提示词。
- 生图取消和错误提示与聊天分开，生图期间仍可继续发送消息；从输入框上方的“查看生成图片”打开图库。

## 发行渠道

- 当前为独立 MNN 生图版（`mnn-image-gen` / `app.tellev.mnn`），保留本地 SD1.5 / MNN、模型管理和前台保活，同时支持 ComfyUI、NovelAI；使用独立签名及 `-mnn` 预发行渠道，可与正式版共存。
- Local Dream 核心及转换资产采用 CC BY-NC 4.0，仅供非商业使用。

## 版本与验证

- versionName：1.6.2；versionCode：28；最低 Android 12 / API 31。
- MNN 安装包保留本地核心与七个转换资产，仅支持 arm64-v8a。
- 分支分别执行 Release 单元测试与发行构建，核验包名、原有签名、APK 内容和 SHA-256。
- 回归测试覆盖生图成功、失败、取消、旧记录迁移及后续聊天，检查上下文、预设和变量保持隔离。
- 用户已确认正式版远端 ComfyUI 生图及隔离修复实测通过；MNN 本地推理本次未单独进行真机验收。
- 安装包 SHA-256 见对应 GitHub Release。
