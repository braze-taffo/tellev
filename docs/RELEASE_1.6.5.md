# tellev 1.6.5 MNN 生图版（预发布）

## 更新内容

### 聊天加载与性能
- 优化进入聊天时的历史会话加载，只读取会话摘要并加载当前会话正文，减少历史数据较多时的等待和内存占用。
- 减少消息正则、Markdown 与富文本的重复处理，并从最新消息开始布局，避免进入聊天时先加载旧消息再跳转。

### 聊天交互与稳定性
- 改善 HTML 卡片与聊天列表之间的滚动衔接，修复部分卡片折叠后仍占用大块空白的问题。
- 优化流式回复时的滚动跟随，减少查看历史消息时被拉回底部的情况。
- 修复部分导入聊天记录在编辑消息时，因回复版本索引或正则标记异常导致的错误。

### 世界书
- 优化单本世界书读取，避免每次打开都解析整个世界书目录。
- 修复条目保存、删除后列表未及时刷新，以及连续修改不同条目时相互覆盖的问题。
- 保存成功后才退出编辑页；保存失败时保留编辑内容并显示错误。
- 修复快速切换世界书或在保存期间离开页面时，旧结果覆盖当前页面或重复返回的问题。

## 版本说明

- MNN 生图版（预发布），支持 Local Dream MNN、ComfyUI、NovelAI。
- 使用独立包名与签名，可与正式版共存；请使用 MNN 渠道安装包更新。
- 最低支持 Android 12。
- 安装包：`tellev-1.6.5-mnn.apk`。
