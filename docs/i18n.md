# 多语言（i18n）架构与维护指南

## 支持语言

简体中文（默认，`res/values/`）、English（`values-en/`）、日本語（`values-ja/`）、한국어（`values-ko/`）。
应用内切换入口：设置 → 语言（跟随系统 / 简体中文 / English / 日本語 / 한국어），选择即时生效（recreate 当前 Activity）。

## 运行机制

- `core/i18n/AppLocale.kt`：语言选择存于 `tellev_prefs` 的 `language_tag`（空串 = 跟随系统）。
  `AppLocale.wrap()` 在 `TellevApplication` 与 `MainActivity` 的 `attachBaseContext` 里包装 base context，
  因此 Compose 的 `stringResource`（走 Activity context）与 Application 级 `getString` 都遵循所选语言。
- `core/i18n/UiStrings.kt`：非 Composable 代码（ViewModel / 引擎 / 适配器等纯类）统一用
  `UiStrings.get(S.<key>, args)` 解析文案。生产环境经 `S.idByName` 查到 `R.string.id` 后走当前语言的
  `Resources`（Activity attach 时重新 init，切换语言后即刻生效）；JVM 单测环境没有 Resources，
  回退到 `S.fallbackZh` 的中文映射，所以既有断言中文消息的测试无需改动。
- `core/i18n/S.kt`：**生成文件，勿手改**（由 `tools/i18n_consolidate.py` 生成），含 key 常量、
  名称→资源 id 映射、单测中文回退映射。

## 字符串的两种写法

| 场景 | 写法 |
| --- | --- |
| @Composable 内 | `stringResource(R.string.key)` / `stringResource(R.string.key, arg)` |
| 非 Composable | `UiStrings.get(S.key)` / `UiStrings.get(S.key, arg)` |
| lambda 内（composable 文件里） | 外层 hoist `val ctx = LocalContext.current`，lambda 内 `ctx.getString(...)` |

插值一律用位置占位符（`%1$s`、`%2$d`）；带占位符的字符串里字面 `%` 写 `%%`；
含 `%model%` 这类非占位符 `%` 的条目由脚本自动加 `formatted="false"`。

这类字面 `%` 条目**不能接收格式化参数**：`String.format` 会把 `%m`、`%=` 当成转换符，
抛 `UnknownFormatConversionException`。所以它们只能经无参形式取用
（`stringResource(R.string.key)`、`UiStrings.get(S.key)`）；要传参只能先把字面 `%`
改写成位置占位符。`AppLocale.storedTag` 也不能用 `base.applicationContext` 取偏好——
`attachBaseContext` 阶段它还是 null（见 `AppLocale.kt` 注释）。

## 新增/修改文案的流程

1. 在代码里用上面的两种写法引用 key（新 key 起一个 snake_case 名，模块前缀见 `_i18n/*.tsv`）。
2. 在对应的 `_i18n/<模块>.tsv` 里加一行 `key<TAB>中文原文`。
3. 在 `_i18n/translations.tsv` 里加一行 `key<TAB>en<TAB>ja<TAB>ko`（缺失时该语言回退中文，脚本会告警）。
4. 运行 `python tools/i18n_consolidate.py` 重新生成四套 `strings.xml` 与 `S.kt`。
   脚本会校验：key 命名合法、跨文件不重复、代码引用与 TSV 双向一致、占位符用法。

## 刻意不翻译的内容（by design）

- 发给 LLM 的提示词/模板、工具协议诊断（改动会影响模型行为，且被单测断言）。
- 持久化数据值：预设名「默认聊天」、记忆 stage 文本、导入导出的字段与等值比较字符串。
- 日志、开发者异常文本、正则/JSON key、技术字面量。
- `nav_qq_group_name`（tellev酒馆交流群）：QQ 群真名，专有名词不译（en/ja/ko 回退中文）。
