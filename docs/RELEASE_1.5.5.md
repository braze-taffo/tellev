# tellev v1.5.5

本版本重点改善聊天与变量保存的可靠性，并推进动态角色卡和提示词模板的兼容处理。

## 更新内容

- 聊天和扩展设置接入日志写入、原子替换与恢复机制；并发聊天修改按消息和字段合并，减少旧快照覆盖新数据。
- 生成、会话切换等操作等待已接纳的写入；保存失败时报告错误，避免依赖未保存状态继续操作。
- 切换会话时重建消息 WebView，并拒绝来自旧会话页面的过期写入请求。
- 完善消息批量修改、swipe 数据和未知字段保留，补充与固定上游消息样例的对照测试。
- 内置固定版本的 MVU/Zod 资源，角色与预设脚本按独立模块加载；提示词模板接入真实 EJS 执行。
- 优化部分大型 HTML 消息的正则匹配，避免在缺少字面量后缀时重复扫描。

## 已知限制

本版本不代表完整 MVU 或酒馆助手兼容验收通过。变量引用及部分错误行为仍存在上游差异，完整事件生命周期和最终提示词一致性仍待验证，详见 [MVU 兼容实施与验收记录](MVU-COMPATIBILITY.md)。用户已确认自行完成真机复验，未逐项提供最低 Android 版本、Sakura 或三轮对话的测试范围。
