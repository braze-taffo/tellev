# AI 协作制卡实施进度

工作树：`codex/ai-card-creation`。本工作树从官方 `master` 的 `fc145139` 建立，未修改另一个 AI 正在处理的提示词引擎工作树，也未同步到 MNN 分支。

## 已实现

- 角色卡/世界书入口、独立创作会话、对话和结构化草稿；草稿存于应用私有目录，可重新打开。
- 创作 agent 使用当前选中的文字供应商连接，使用自己的系统指令和固定生成参数；不读取聊天生成预设，不调用聊天提示词引擎。
- 角色卡字段、备选开场、示例对话、系统提示、历史后提示、内嵌世界书的编辑及本地保存。
- 世界书对话创作；粘贴或导入 UTF-8 长文本，逐段提炼、逐段保存进度、失败后继续。保留原文及 SHA-256 校验，条目引用必须能在对应原文段定位；重复标题会提示用户核对。
- 无脚本、无外部资源的 HTML/CSS 开场前端草稿、隔离 WebView 预览及可移植性检查。保存时对角色卡执行 V2 JSON 导出回导检查。

## 已验证

- `:app:assembleDebug` 成功。
- `CreationFeatureTest` 覆盖长文无截断分段、原文证据过滤、草稿恢复、agent 独立参数、角色卡与世界书格式往返，以及 Tellev 前端解析入口；测试通过。
- 本地 SillyTavern 源码显示：首条消息支持 HTML，但消息渲染受 DOMPurify 与“显示标签”用户设置影响。当前生成范围采用无需酒馆助手/提示词模板的静态 HTML 和原生 `<details>` 交互。
- 在隔离的 SillyTavern 1.18.0 实例中，用测试夹具导入 V2 角色卡；导出结果保留首条消息 HTML、示例对话和内嵌世界书。打开角色聊天时，世界书出现导入提示；首条消息中的 `<details>` 可以点击展开并显示内容。夹具不是模型实际生成的角色卡。
- ADB 将 `app.tellev.debug`（1.6.6-debug）安装到设备 `HA25GHH4`，返回 `Success`；核对了已安装 APK 路径及 `app.tellev.MainActivity` 启动入口。功能由用户在设备上测试。
- 用户设备截图发现创作 agent 的 `exampleMessages` 输出存在非法 JSON 转义。现已要求模型明确遵守字符串转义，解析失败时独立调用一次格式修复；连续失败会提示重试，不应用该轮草稿。重新打开尚未获得回复的草稿时也会显示重试入口。相关回归测试与 `assembleDebug` 通过，更新包已通过 `adb install -r` 安装到同一设备。

## 尚未完成的验收

- 用户新增体验要求（2026-09-25 凌晨，待早上实施）：长时间创作和长文世界书提炼不能只显示转圈。应像编程工具一样，实时呈现模型正在输出的思考/文字；同时显示当前阶段、分段进度和已完成内容，让用户知道处理到哪里。优先使用供应商实际返回的流式内容；不伪造模型未提供的内部思考。页面重开后仍应能看见已持久化的提炼进度。保持创作 agent 与聊天预设/提示词引擎隔离。
- 尚未用真实模型生成的同一张卡在 SillyTavern 与 Tellev 完成端到端验收。
- 尚未在 Tellev Android 设备上验证实际对话、世界书触发和前端交互；安装与启动入口核对不代表功能验收。
- 更复杂的脚本状态面板和同层前端尚未纳入生成范围。扩展前须先定义两端共有的运行接口，并用真实卡片测试。
- 与并行提示词引擎修复合并后，需要在官方与 MNN 两个渠道分别构建和验证。当前代码不可标记为“双端验收通过”或发布。

原计划见官方工作树中的 `docs/AI_CARD_CREATION_PLAN.md`。实现后的兼容失败频率仍需代表样本实测，当前没有概率结论。
