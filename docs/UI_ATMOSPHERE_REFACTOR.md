# Android 正式版前端重构 · 2026-10-01

本次以角色收藏和故事氛围为主：暖纸色与铜色强调色、深色主题、自适应角色封面网格、统一圆角与文字层级。修改直接保留在当前 `master` 工作目录，保留动工前已经存在的修改。

界面变化：

- 角色列表和聊天选角页使用同一组封面卡片，展示原角色图片、名称、标签；无图片时使用渐变占位。角色详情增加封面与头像区，原编辑字段及保存入口保留。
- 世界书列表展示条目数、启用状态、开关和操作菜单；详情页调整层次、间距与开关布局。
- 聊天标题增加头像，输入区和附件栏重新排版；设置分为“模型与预设、身份、外观、资料”，扩展与 AI 创建页统一视觉。
- 中、英、日、韩新增文案齐全，既有主题、语言和透明度设置继续生效。

修复的交互问题：

- 底部导航原先比较 `characters` / `world` 父级图路由，但列表实际路由是 `characters/list` / `world/list`，所以列表误隐藏了底部导航。现在用明确的顶层页面集合判断，详情及编辑页仍隐藏导航。
- 在角色列表触发系统返回键或边缘返回手势，弹出“你真的要退出吗？”和“是 / 否”。“否”留在列表，“是”关闭 Activity。返回处理放在角色列表的导航节点内，确保优先于 NavHost 的返回处理；详情页保留正常返回。
- 主窗口明确使用 `adjustResize`，修复软键盘出现时整页平移、角色栏和消息消失的问题。

本次修改边界：

- 对动工前所有 `app/src` 文件的 SHA-256 快照进行比较；本次已有文件变化限定为 13 个界面文件与主窗口的键盘布局属性。
- 139 个核心逻辑和 ViewModel 文件与快照一致；模型调用、角色卡/世界书解析、存储和导出逻辑未被本次修改。
- 聊天输入区内的附件持久化函数与快照完全一致。原有聊天渲染与兼容性改动保留。
- 封面直接读取已有头像图片，没有新存储字段、数据迁移或新增依赖；测试样例仅放入本次模拟器，原始角色卡文件未改写，也未打入 APK。
