# v1.7.1.9 · 独立导入正则

- 在「扩展 → 导入正则」直接读取酒馆导出的正则 JSON，支持单条规则和多条规则数组。
- 导入前预览名称、数量与启用状态，可选择全局或搜索指定角色；没有角色时也能导入全局规则。
- 同一范围内按名称覆盖，保留目标规则 ID、位置和其他规则，启用状态采用导入文件；重名冲突或无效条目会阻止整批导入并说明原因。
- 全局规则单独列出，角色规则在角色资源卡中管理，均可启停或确认删除；规则和状态随备份恢复。
- 全局规则按「全局 → 预设 → 角色」顺序参与聊天与提示词处理，显示规则变化及时刷新，已保存消息不追溯执行普通替换。
- 更新简体中文、英文、日文、韩文的版本指引与新手引导。

Android 正式版，包名 `app.tellev`，版本 `1.7.1.9`（51），沿用官方签名，可覆盖安装。

入口：**扩展 → 导入正则 → 选择 JSON → 选择全局或指定角色 → 确认导入**。同名规则会覆盖，请先核对目标范围。文件上限为 12 MB。
