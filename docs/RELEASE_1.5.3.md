# tellev v1.5.3

本版本重点改善主题、聊天呈现和预设编辑体验，并新增 `tellevclick` 模型服务入口。

## 主题与聊天

- 新增暖橘主题，并可在设置中切换回经典蓝紫配色。
- 修复暖橘主题下底部导航栏仍残留紫色的问题。
- 聊天对白引号跟随当前主题色高亮。
- 消息改用半透明气泡，使聊天背景与文字层次更协调。
- 修复输入时输入栏悬空以及卡片插图随键盘跳缩的问题。
- 移除 WebView 自动对比度脚本，避免改写角色卡原有视觉设计。

## 预设与模型服务

- 生成预设详情改为全屏编辑器，复杂提示词和参数更易浏览与调整。
- 新增预置服务商 `tellevclick`，预填 `https://tellev.click/v1` OpenAI 兼容接口地址。
- `tellevclick` 支持模型列表读取和聊天补全；正式版用户仍需填写自己的密钥并选择模型。

## 版本信息

- `versionName`: `1.5.3`
- `versionCode`: `20`
- 最低系统：Android 12 / API 31
- SillyTavern 兼容基线：1.18.0
