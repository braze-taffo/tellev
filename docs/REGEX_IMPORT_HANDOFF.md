# 独立导入正则交接

日期：2026-10-29。实现基于官方 Android `master` 的 `0344ffa`；后续按用户要求准备 `1.7.1.9`（51）正式发行，发行验证见 `RELEASE_1.7.1.9_VALIDATION.md`。

## 使用

“扩展 → 导入正则”，选择酒馆导出的单条 JSON 对象或规则数组。预览名称、数量和启用状态，选择全局或搜索指定角色后确认。

- 目标范围按 `scriptName` 精确匹配覆盖，保留目标 ID 和顺序；新名称追加并生成独立 ID。未知字段完整保留，启用状态采用导入文件。
- 导入批次内重名，或待覆盖名称在目标内不唯一，整批报错，不写入。校验所有条目后才保存；读取上限为 12,000,000 字节。
- 全局和角色规则均支持开关及确认删除。全局规则位于扩展页顶部，角色规则位于角色资源卡的展开列表中。
- 全局规则独立保存在 `st-data/extensions/_global-regex.json`，使用写入日志并随备份恢复。角色规则保存在原卡的 `extensions.regex_scripts`。

## 执行接入

全局 → 预设 → 角色，沿用现有处理阶段、位置、深度和编辑条件。全局快照随聊天文本上下文、提示词请求和渲染上下文显式传递；渲染上下文本身是 `RenderInputs` 缓存键的一部分。变更通知刷新聊天快照，已有消息不追溯执行普通替换。

已接入用户输入、回复保存、中断回复、编辑、开场白与切换开场白、普通及助手生成请求、世界书提示词和思考内容显示。没有新增正则编辑器、预设范围导入、导出或脚本 API。
