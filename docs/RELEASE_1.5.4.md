# tellev v1.5.4

本版本重点改善大型角色卡和长聊天记录场景下的响应速度与稳定性，并新增聊天气泡不透明度调节。

## 性能与稳定性

- 将角色卡、会话与世界书的加载和集合处理移出主线程，角色脚本改为后台加载，让聊天内容更早显示。
- 精简扩展上下文快照，并对同一任务内的重复读取复用结果，减少大型角色卡和长对话的重复序列化开销。
- 角色切换时仅向扩展分发最近的已渲染消息，避免长聊天记录产生集中事件风暴。
- 修复动态 HTML 卡片的高度反馈循环，并对频繁尺寸变化进行合并与过滤，降低界面卡顿和 ANR 风险。

## 聊天外观

- 设置页新增聊天气泡不透明度滑块。
- 不透明度设置同步应用于消息气泡、思考内容、输入框和操作按钮。
- 保留原有 60% 不透明度作为默认值，已有用户升级后视觉效果保持不变。
