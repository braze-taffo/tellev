# tellev v1.6.0.1

修复 MVU 对话的消息保存冲突与错误提示，两条分发渠道同步更新。

## 更新内容

- 修复生成完成后 MVU 改写正文时，旧 `raw.mes` 快照被误判为并发修改，导致变量保存失败、生成暂停或会话无法关闭的问题。
- 正文保存失败时直接返回实际原因，避免后续被 MVU 提交超时报错掩盖；写入成功后同步刷新上下文。
- 保留真正并发修改正文时的冲突检查。
- 正式版仅提供 ComfyUI 与 NovelAI 远程生图，不包含本地生图；同时包含统一生图设置入口与五分钟模型网络超时。
- 生图版继续保留 MNN OpenCL 本地生图、引擎前台保活与模型管理功能。

## 版本与分发

- `versionName`: `1.6.0.1`
- `versionCode`: `25`
- 最低系统：Android 12 / API 31；目标 SDK：36。
- 正式版：`app.tellev`，标签 `v1.6.0.1`，附件 `tellev-1.6.0.1.apk`。
- 生图版：`app.tellev.mnn`，标签 `v1.6.0.1-mnn`，附件 `tellev-1.6.0.1-mnn.apk`，保持预发布。
- 两个渠道使用各自原有签名与包名，可分别覆盖升级；生图版的 Local Dream 本地生图核心继续遵循 CC BY-NC 4.0，仅供非商业使用。

## 验证范围

- 修复前，真实 JSONL 存储回归测试复现 `Conflicting stale update at message[reply].raw.mes`；修复后通过，并确认真正正文冲突仍被拒绝。
- 修复包正式版 645 项、生图版 662 项 Debug 单元测试通过，两版 Lint 无错误；JavaScript 兼容测试 5 项通过。
- 用户提供的 3.1.1 卡两个开场各两轮合成对话脚本回放通过。此回放使用实际 Schema 和维护脚本，原生存储边界为模拟实现，不覆盖预设提示词或正则应用。
- 两个修复包已通过 ADB 覆盖安装，用户于 2026-09-07 明确反馈测试完毕、没有问题。该测试对应本次报错场景，不扩展为所有 MVU 接口与卡片验收。
- 发行包在同一修复代码基础上升级版本号并重新构建；APK 包名、签名和嵌入资源哈希在上传前复核，最终文件 SHA-256 记录在 GitHub Release 中。
