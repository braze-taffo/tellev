## 1.7.1.9: 정규식 개별 가져오기

캐릭터 카드를 다시 가져오지 않고 SillyTavern에서 내보낸 정규식 JSON을 불러올 수 있습니다. 단일 규칙과 여러 규칙의 배열을 지원합니다.

<!-- where -->
- 확장 → 정규식 가져오기

<!-- steps -->
1. "정규식 가져오기"를 눌러 JSON 파일을 선택하고 이름, 개수, 사용 상태를 확인합니다.
2. 모든 캐릭터에 적용하려면 "전역", 특정 캐릭터에 적용하려면 "캐릭터 지정"을 선택하고 검색합니다.
3. "가져오기"를 누릅니다. 캐릭터가 없어도 전역 규칙을 가져올 수 있습니다.

## 같은 이름 덮어쓰기와 가져오기 검사

선택한 범위에서 이름이 같은 규칙을 덮어쓰고 다른 규칙은 유지합니다. 사용 상태는 파일을 따릅니다. 이름 중복이나 잘못된 항목이 있으면 전체 가져오기를 중단하고 이유를 표시합니다.

<!-- where -->
- 확장 → 정규식 가져오기 → 미리보기 및 범위 선택

<!-- steps -->
1. 가져오기 전에 적용 범위를 확인합니다. 같은 이름 덮어쓰기는 선택한 범위에만 적용됩니다.
2. 파일이나 대상 범위에서 같은 이름을 하나로 특정할 수 없다면 중복을 해결한 뒤 다시 가져옵니다.
3. 완료 후 추가 및 덮어쓰기 개수를 확인합니다. 파일 크기는 12 MB 이하여야 합니다.

## 사용 상태 변경과 삭제

전역 규칙은 별도 목록에, 캐릭터 규칙은 캐릭터 리소스 카드에 표시됩니다. 규칙과 사용 상태는 백업에도 저장됩니다.

<!-- where -->
- 확장 → 전역 정규식
- 확장 → 캐릭터 리소스 → 정규식 스크립트 펼치기

<!-- steps -->
1. 규칙 옆 스위치로 사용 여부를 바꿉니다. 전역, 프리셋, 캐릭터 순서로 처리합니다.
2. 삭제 아이콘을 누르고 확인하면 해당 규칙만 삭제합니다.
3. 표시 규칙을 변경하면 채팅 화면에 반영됩니다. 저장된 메시지의 일반 치환은 다시 실행하지 않습니다.
