## 1단계: 모델 서비스 설정

Tellev에는 모델이 들어 있지 않습니다. 직접 쓰는 API 서비스(OpenAI 호환 엔드포인트나 중계 서비스)를 연결해야 합니다.

<!-- where -->
- 설정 → 모델 서비스 → "모델 서비스 설정 관리"

<!-- steps -->
1. "설정" 탭에서 "모델 서비스"의 "모델 서비스 설정 관리"를 열고 연결을 추가한 뒤 API 주소, 키, 모델 이름을 입력하세요.
2. 생성 파라미터(생성 프리셋)도 "설정" 탭에 있습니다. 샘플링이나 컨텍스트 상한을 조정할 때 그곳에서 하세요.
3. "채팅" 탭에서 메시지를 보내 답장이 오면 설정이 끝난 것입니다.

## 2단계: 첫 캐릭터 만들기

세 가지 방법이 있습니다. 기존 카드를 가져오거나, 직접 만들거나, AI에게 맡기는 것입니다.

<!-- where -->
- 하단 "캐릭터" 탭
- 캐릭터 탭 오른쪽 위 "캐릭터 카드 가져오기"
- 캐릭터 탭 하단 "새 캐릭터", 상단 "AI 생성"

<!-- steps -->
1. "캐릭터" 탭에서 오른쪽 위 "캐릭터 카드 가져오기"를 눌러 PNG나 JSON 카드를 고르세요. 술관 캐릭터 카드는 그대로 쓸 수 있습니다.
2. 직접 만들려면 하단 "새 캐릭터"에서 이름, 설정, 첫 메시지를 채우세요.
3. 어떻게 써야 할지 모르겠다면 상단 "AI 생성"에서 아이디어를 한 문장으로 말하고 초안을 받아 다듬으세요.

## 3단계: 대화 시작하기

채팅 탭이 메인 화면입니다. 캐릭터 선택, 세션 시작, 메시지 전송을 여기서 합니다.

<!-- where -->
- 하단 "채팅" 탭

<!-- steps -->
1. "채팅" 탭에서 목록의 캐릭터를 누르면 새 세션이 열립니다.
2. 하단 입력창에 쓰고 전송을 누르면 대화가 시작됩니다.
3. 상단 "세션"에서 세션을 만들거나 지울 수 있고, "더 많은 옵션 → 페르소나 전환"으로 내 설정을 바꿉니다.
4. "더 많은 옵션"에는 채팅 배경과 장기 기억 진입점도 있습니다.

## 4단계: 써 볼 만한 기능

대화 외에도 미리 설정해 두면 좋은 기능이 몇 가지 있습니다.

<!-- where -->
- 설정 → 이미지 생성(엔진 및 모델)
- 확장 → 장기 기억
- 하단 "월드북" 탭
- 설정 → 테마, 언어

<!-- steps -->
1. 이미지 생성: "설정 → 이미지 생성(엔진 및 모델)"에서 엔진을 설정하면 채팅 입력줄에 생성 버튼이 생기고, 만든 이미지는 채팅 갤러리에 들어갑니다.
2. 장기 기억: "확장" 탭에서 켜면 긴 대화에서도 앞선 설정을 잊지 않습니다.
3. 월드북: 캐릭터에 설정집을 붙여 두면 세계관 세부를 대화에서 자동으로 활용합니다.
4. 테마와 언어: "설정"에서 테마 색상, 말풍선 불투명도, 인터페이스 언어를 바꿀 수 있습니다.
