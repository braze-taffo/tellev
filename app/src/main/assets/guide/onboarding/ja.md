## ステップ1：モデルサービスを設定する

Tellev 自体はモデルを内蔵していません。自分の API サービス（OpenAI 互換のエンドポイントや中継サービス）に接続します。

<!-- where -->
- 設定 → モデルサービス →「モデルサービスの設定を管理」

<!-- steps -->
1. 「設定」タブで「モデルサービス」の「モデルサービスの設定を管理」を開き、接続を追加して API の URL・キー・モデル名を入力します。
2. 生成パラメータ（生成プリセット）も「設定」タブにあります。サンプリングやコンテキスト上限を調整したいときはそこへ。
3. 「チャット」タブでメッセージを送り、返信が来れば設定完了です。

## ステップ2：最初のキャラクターを用意する

方法は3つ：既存のキャラカードをインポートする、自分で作る、AI に書かせる。

<!-- where -->
- 画面下部の「キャラクター」タブ
- キャラクタータブ右上の「キャラカードをインポート」
- キャラクタータブ下部の「新規キャラクター」、上部の「AI作成」

<!-- steps -->
1. 「キャラクター」タブで右上の「キャラカードをインポート」を押し、PNG か JSON のカードを選びます。酒場のキャラカードはそのまま使えます。
2. 自分で書くなら下部の「新規キャラクター」から名前・設定・最初のメッセージを入力します。
3. 書き方が分からなければ上部の「AI作成」で、アイデアをひとこと伝えて下書きを作らせます。

## ステップ3：会話を始める

チャットタブがメイン画面です。キャラクター選び、セッションの開始、送信はここで行います。

<!-- where -->
- 画面下部の「チャット」タブ

<!-- steps -->
1. 「チャット」タブを開き、一覧のキャラクターをタップすると新しいセッションが始まります。
2. 下部の入力欄に書いて送信すると会話が始まります。
3. 上部の「セッション」でセッションの作成・削除、「その他のオプション → ペルソナを切り替え」で自分の設定を変更できます。
4. 「その他のオプション」にはチャット背景や長期記憶の入口もあります。

## ステップ4：試してみる価値のある機能

会話以外にも、早めに設定しておくと役立つ機能があります。

<!-- where -->
- 設定 → 生図（エンジンとモデル）
- 拡張 → 長期記憶
- 画面下部の「ワールドブック」タブ
- 設定 → テーマ、言語

<!-- steps -->
1. 画像生成：「設定 → 生図（エンジンとモデル）」でエンジンを設定すると、チャット入力欄に生成ボタンが現れ、生成した画像はチャットのギャラリーに入ります。
2. 長期記憶：「拡張」タブで有効にすると、長い会話でも以前の設定を忘れにくくなります。
3. ワールドブック：キャラクターに設定資料を持たせると、世界観の細部を会話で自動的に使ってくれます。
4. 見た目と言語：「設定」でテーマカラー、バブル不透明度、表示言語を変更できます。
