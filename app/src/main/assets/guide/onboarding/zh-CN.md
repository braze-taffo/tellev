## 第一步：配置模型服务

Tellev 本身不带模型，需要连上你自己的 API 服务：OpenAI 兼容接口、常见中转站都可以。

<!-- where -->
- 设置 → 模型服务 →「管理模型服务配置」

<!-- steps -->
1. 打开「设置」页，在「模型服务」里点「管理模型服务配置」，新增一个连接并填好 API 地址、密钥与模型名。
2. 生成参数（预设）在「设置 → 生成预设」里，需要调整采样参数或上下文上限时去那里。
3. 回「聊天」页发一条消息，能收到回复就说明配置好了。

## 第二步：拿到第一个角色

三种方式：导入现成的角色卡、自己新建、或者让 AI 帮你写一张。

<!-- where -->
- 底部「角色」页
- 角色页右上角「导入角色卡」
- 角色页底栏「新建角色」、顶栏「AI 创建」

<!-- steps -->
1. 进「角色」页，点右上角「导入角色卡」，从文件里选 PNG 或 JSON 卡；酒馆的角色卡可以直接用。
2. 想自己写就点底栏的「新建角色」，填写名称、人设与开场白。
3. 不知道怎么写就点顶栏「AI 创建」，用一句话描述想法，让 AI 生成一版再改。

## 第三步：开始聊天

聊天页是主界面：选角色、开会话、发消息都在这里。

<!-- where -->
- 底部「聊天」页

<!-- steps -->
1. 进「聊天」页，从列表里点一个角色，就开了一条新会话。
2. 在底部输入框写内容，点发送开始对话。
3. 顶栏「会话」用来新建或删除会话；「更多选项 → 切换人设」用来换你自己的身份设定。
4. 「更多选项」里还能设置聊天背景、切换人设、打开长期记忆。

## 第四步：值得一试

除了聊天，还有几个开箱可用的功能，值得先试一试。

<!-- where -->
- 设置 → 生图（引擎与模型）
- 扩展 → 长期记忆
- 底部「世界书」页
- 设置 → 主题、语言

<!-- steps -->
1. 生图：在「设置 → 生图（引擎与模型）」配好引擎后，聊天输入栏会多出一个生图按钮，配好的图会进聊天图片画廊。
2. 长期记忆：在「扩展」页打开，长对话也不容易忘记前面设定。
3. 世界书：给角色加一套设定集，模型会在对话里自动用上世界观细节。
4. 外观与语言：在「设置」里换主题色、气泡不透明度与界面语言。
